# تصميم الهوية والاتحاد والصلاحيات — [الحل]

> اختر الأقسام المناسبة. ميّز مزوّد الهوية المستخدم فعليًا عن البدائل المقترحة،
> ولا تدرج أسرارًا أو رموز وصول أو بيانات اعتماد حقيقية.

## المتطلبات والاختيار

[المستخدمون والجهات، العملاء والقنوات، SSO وMFA والاتحاد، دورة حياة الحساب،
الصلاحيات، متطلبات التوفر، القيود والجهة المالكة. قارن Keycloak وWSO2
Identity Server وDuende أو المزوّد القائم حسب الحاجة مع الإصدار والدعم
والترخيص ومسؤولية تشغيل واجهات الدخول وإدارة المستخدمين.]

## النشر والتكامل والتشغيل

[الدومين العام وissuer المستقر، TLS والـproxy، قاعدة البيانات والمفاتيح
والأسرار ودورانها، التوسع والتعافي، مزامنة الوقت وملكية التشغيل. افصل
استضافة خادم الهوية عن IIS الذي قد يعمل كـreverse proxy. تحقق من توافق
SharePoint/Mendix والعملاء مع الإصدارات والتدفقات الفعلية.]
