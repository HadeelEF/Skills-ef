## 3. دوافع المعمارية والقيود

| --- | --- | --- | --- |

[أحجام الاستخدام والبيانات، الاستضافة، المهارات والتشغيل والميزانية
والمدة إن كانت مؤثرة. اربط سيناريوهات الجودة بقالب NFR.]

[ثبّت مسار المشروع: تطوير مخصص .NET + React.js + SQL Server على Windows/IIS،

أو React PWA عند حاجة المشروع المخصص. ميّز الأنظمة الخارجية المتكامل معها عن
مكونات بناء المشروع. وثّق أي استثناء بتوجيه صريح من المستخدم؛ المقترح ليس اعتمادًا.]

## 6. معمارية Backend

[حدود الوحدات/الخدمات، اتجاه الاعتماديات، قواعد الأعمال، العقود، التزامن،
المعاملات، الأعمال الخلفية والآثار الخارجية. وضح سلوك الفشل والتعافي.]

[عند انطباقها اربط عقود cache/Redis والمهام والأحداث، موضع التنفيذ،
متانة القبول والنشر، retries وdeduplication وحدود الآثار غير القابلة للعكس.]

## 7. معمارية Web وMobile

[React/Next.js وأساليب العرض والاستضافة، توزيع المسؤولية مع .NET، الهوية
وإدارة الحالة والعقود. للجوال: React Native، توافق العملاء، إمكانات الجهاز،
offline والمزامنة إذا طلبا، النشر والتحديث. حدد RTL والإتاحة وقيود UX.]

[لـMendix أو SharePoint: صمّم قنوات المشروع داخل منصته وأدواتها المدعومة،
وحدد ملكية المحتوى والمعاملة. لا تضف واجهة أو Backend مستقلًا. افصل تكامل
الأنظمة الخارجية عن تقنيات تنفيذ المشروع، وبيّن قيود المنصة وأدلة توافقها.]

## 8. معمارية البيانات

[النموذج المفهومي/المنطقي، مصدر الحقيقة والملكية، القيود، تصنيف البيانات،
التاريخ والاحتفاظ، الملفات، التحليل، الترحيل. حدد محرك قاعدة البيانات
وإصدارها وخيار الاستضافة بدليل؛ لا تستنتج المحرك من اسم ApsaraDB وحده.]

## 9. معمارية التكامل والاتصالات

[API مقابل batch/CDC/events، العقود والنسخ والتكرار وإعادة المعالجة.
لـEF افصل Apigee وInformatica SaaS وSecure Agent ونقل البيانات والتحكم.
اربط كل تدفق بمصفوفة الشبكة وحالة التحقق من المسار.]

## 10. الأمن والهوية وحدود الثقة

[تدفقات الهوية، الصلاحيات على الموارد، الخدمات والحسابات المميزة، حماية
الأسرار والشهادات، التشفير، التهديدات المهمة وآليات الحد منها والأدلة.]

[عند انطباقها اربط عقد الهوية: مزوّد قائم أو مقترح، federation/SSO،
PKCE/BFF/M2M حسب العميل، دورة الحساب، إلغاء الجلسات والصلاحيات ومدة تأخره.]

## 11. النشر والاستضافة والتشغيل

[مخطط نشر، متطلبات runtime، البيئات والعزل، إعدادات وأسرار، CI/CD، مراقبة
وسجلات وتدقيق، مالكو التشغيل، الاعتماديات الخارجية ونقاط الفشل المشتركة.]

[ميّز static React عن Next.js server runtime وعن ASP.NET Core على IIS،
وعامل Windows مستقل وMendix Runtime ومكونات SharePoint. اربط مصفوفة
الإصدارات المدعومة بدل افتراض أن جميع المكونات تستخدم أحدث إصدار واحد.]

## 12. الجودة والسعة والتكلفة والتعافي

[سيناريوهات NFR وأهدافها أو حالتها غير المحسومة، نموذج الحمل، السعة
المقدرة مقابل المقاسة، تكلفة التأسيس والتشغيل والنقل والتراخيص، HA وDR
وRTO/RPO والنسخ والاسترجاع مع مصادر الأرقام وافتراضاتها.]
