# حزمة تنفيذ للـAI — [الميزة/الشريحة]

هذه حزمة تسليم يصوغها Solution Architect للمطوّر أو وكيل التنفيذ.
خطوات التنفيذ أدناه موجّهة لذلك المستلم؛ دور المعماري هو التصميم وتحديد
القيود ومعايير القبول ومراجعة الأدلة، دون تنفيذ الكود أو تعديل نموذج التطبيق.


> املأ حسب المهمة وأزل غير المنطبق. تستخدم لتسليم التصميم إلى المنفذ؛
> لا تجعل إعدادها مرحلة موافقة إضافية لكل تعديل صغير.
