# مراجعة التصميم والتسليم والتنفيذ

## Review scope

حدد ما تراجعه: متطلبات، مواصفات، ملف Figma، لقطات، أو منتج يعمل. اختر
فحوصًا تجيب عن الطلب والمخاطر المتبقية. تعديل نص لا يستلزم تدقيق منصة
كاملة، ومنصة جديدة لا تكفيها مراجعة الشاشة الافتراضية وحدها.

استخدم مرجع الهوية وقواعد المشروع والإتاحة المناسبة. فرّق بين مخالفة
موثقة ومشكلة استخدام ملحوظة وتفضيل بصري مقترح. اذكر الدليل عندما يكون
أساسًا لتغيير مؤثر، ولا تحول ذوقًا شخصيًا إلى قاعدة رسمية.

## Handoff readiness

اقرأ التسليم كما لو أن المطور بدأ جلسة جديدة. تحقق من:

- وضوح نقطة البدء والنطاق والمسار الذي سينفذه أولًا.
- تغطية المتطلبات المهمة بشاشات وإجراءات ونتائج قابلة للتتبع.
- اكتمال البداية والإتمام والتعافي، واتساق التسميات وحالات العمل.
- تحديد التكوين والقيم والقيود التي تمنع اختراع قرارات UI أساسية.
- اكتمال النصوص والحالات ضمن النطاق بالعربية والإنجليزية، والفروق
  في الاتجاه والتجاوب والتنسيق وتبديل اللغة.
- وجود قواعد التحقق والصلاحيات من مصادرها، مع توضيح الاعتمادات المفتوحة.
- حل مسارات الأصول وروابط المستندات والمكونات ومعرفات المحتوى.
- وجود معايير قبول مرتبطة بنتائج فعلية وبيان ما يحتاج تنفيذًا أو تكاملًا.

عالج التناقض في مصدره المشترك وحدّث ما يعتمد عليه. لا تنسخ قاعدة معدلة
في شاشة واحدة وتترك بقية النظام بقيم مختلفة دون سبب.

## Rendered review

عند توفر نتيجة مرئية، افحصها مقابل الحالة والمحتوى والمقاس المقصود.
استخدم أدوات العرض والمتصفح المتاحة ضمن صلاحيات المهمة، وتحقق من:

| المجال | الدليل المطلوب |
| --- | --- |
| الهوية | الأصل الصحيح، النسبة والمساحة الآمنة، الألوان، والخط والوزن الفعليان حيث يمكن فحصهما |
| الشكل | التسلسل والكثافة والمحاذاة والمسافات والقص والتفاف النص واتساق المكونات |
| اللغتان | RTL/LTR، المحتوى المختلط والطويل، اكتمال النصوص، وتبديل اللغة وحفظ السياق |
| التكيف | العرض الضيق والمتوسط أو الحالات التي تغير التخطيط، والتكبير عند انطباقه |
| التفاعل | المسار الرئيسي، تحقق المدخلات، الانشغال والفشل والتعافي والفراغ، بحسب النطاق |
| الإتاحة | التباين المحسوب عند الحاجة، لوحة المفاتيح والتركيز والتسميات والعلاقات الدلالية |

لا تستنتج تحميل خط من وجود اسم في CSS أو من تشابه شكله وحده. لا تستنتج
صلاحيات خادم أو نجاح عملية فعلية من زر ظاهر. اللقطة تثبت مظهرًا في لحظة
ومقاس محددين؛ لا تثبت عمل النقر أو لوحة المفاتيح أو حفظ المدخلات.

نماذج قبول قابلة للتكييف مع المهمة:

- بعد رفض حقل، ترتبط الرسالة به وتبقى القيم الأخرى ويستطيع المستخدم
  الوصول إلى التصحيح بلوحة المفاتيح.
- عند تغيير اللغة تبقى الشاشة والعنصر المحدد والمدخلات وفق السلوك الموثق؛
  يتغير العرض دون تغيير القيمة الداخلية أو معنى الإجراء.
- في العرض الضيق مع عنوان طويل، يبقى الإجراء الأساسي والمحتوى الضروري
  قابلين للوصول ولا يحجبهما شريط ثابت.
- عند عدم وجود نتائج، تبقى شروط البحث وتوجد طريقة واضحة لتعديلها.

هذه أمثلة لدقة القبول، وليست اختبارات إلزامية لكل صفحة. الفحص الآلي
والمراجعة اليدوية واختبار مستخدم فعلي أنواع أدلة مختلفة؛ لا تستبدل أحدها
باسم الآخر.

## Findings

لكل ملاحظة قابلة للتنفيذ، سجل: **الموضع والحالة واللغة، المشكلة، أثرها،
الدليل، التصحيح، وطريقة التحقق**. أضف المقاس أو الصورة أو رابط الإطار
حين يفيد في إعادة إنتاجها.

رتّب العمل بحسب الأثر:

| الأولوية | معنى عملي |
| --- | --- |
| حرجة | تمنع مهمة أساسية أو تسبب فقدًا مهمًا أو نتيجة مضللة |
| مرتفعة | تربك المسار أو تمنع فئة من الاستخدام أو تخالف قاعدة هوية مؤثرة |
| عادية | خلل محلي في الاتساق أو المقروئية أو السلوك مع وجود مسار قابل للاستخدام |
| تحسين | اقتراح له فائدة واضحة ويمكن تأجيله دون تعطيل المتطلبات |

وازن الأولوية مع السياق، ولا تمنح عيبًا تجميليًا درجة أعلى لمجرد سهولة
إصلاحه. قدّم أسبابًا قابلة للفحص بدل عبارات «التصميم غير احترافي».

## Completion

عند وجود صلاحية إصلاح ضمن المهمة، نفّذ التصحيح المناسب وحدّث المصدر
التصميمي إذا تغير القرار. وإلا سلّم ملاحظة دقيقة للمنفذ. أعد فحص الجزء
المتأثر والاعتمادات المباشرة؛ وسّع الفحص فقط عند وجود خطر أو بوابة مطلوبة.

بيّن في النتيجة نوع الدليل وحدوده:

- **محدد بالمواصفات:** القرار مكتوب وقابل للتنفيذ.
- **فُحص بصريًا:** راجعت نتيجة مرئية في الحالات المذكورة.
- **اختُبر تفاعليًا:** نُفذت الخطوات ووثّقت النتيجة الفعلية.
- **غير مفحوص أو معتمد على معلومة:** حدّد ما ينقص وأثره على الإكمال.

التسليم الجيد يحقق نطاق الطلب مع ذكر الاعتمادات المتبقية. لا تصف ملفًا
أو نموذجًا بأنه معتمد من EF أو ممتثل بالكامل أو مختبر مع المستخدمين
دون دليل. اذكر «رُوجع مقابل مرجع الهوية المقدم» عند وصف مراجعة الهوية.
