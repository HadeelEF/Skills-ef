# دفتر هندسة العملية وتحسينها

> استخدمه بقدر حجم التحسين؛ افصل البيانات المؤكدة والافتراضات والمقترحات. احتفظ بالقياس غير المتاح كفجوة مع خطة جمع، ولا تملأه بصفر. اربط الرسم من قالب العملية بدل تكراره هنا.

## الهدف والحدود

العملية/الإصدار، مالكها وصاحب السياسة، المستفيد والنتيجة المطلوبة، وحدة الحالة والبداية والنهاية، الخطوات والفرق المشمولة، سبب التحسين ودليله، القيد أو الضابط الذي يجب حفظه:

| المورد | المدخل وضابط قبوله | العملية عالية المستوى | المخرج وضابطه | المستفيد |
|---|---|---|---|---|
| | | | | |

استخدم SIPOC أعلاه فقط إذا احتجت حسم الحدود. اربط As-is وجدول الخطوات ومصدر وصف العمل الفعلي، وحدد اختلافه عن الإجراء المكتوب.

## خط الأساس وعقد البيانات

| المقياس | التعريف/الوحدة والحدود والمقام | المجتمع/الفترة والتقويم | المصدر والنقص/الاستبعاد | خط الأساس ودليله | الهدف وصفته |
|---|---|---|---|---|---|
| | | | | | |

| الخطوة/الفئة | الوارد والزيارات المعادة | الإنجاز الفعلي | الموارد والدقائق المتاحة | السعة وطريقة حسابها | WIP والعمر/الانتظار |
|---|---|---|---|---|---|
| | | | | | |

افصل المنجز عن المفتوح، ومعاملة الأعمال عن زيارة الخطوة، والزمن المنقضي عن جهد الأشخاص. صرّح بافتراضات التوازي والموارد المشتركة ومزيج الحالات قبل الحساب.

## التصميم المستهدف وتتبع أثره

رابط رسم To-be وجدول خطواته، القواعد المتغيرة، حالات الاستثناء والطلبات الجارية، وما بقي بحاجة لقرار:

| As-is Step | To-be Step | نوع التغيير وسببه | الضابط/الدور المتأثر وصاحب القرار | متطلب/UC/قبول/Backlog/RTM |
|---|---|---|---|---|
| | | | | |

## التجربة وإدارة التغيير

الفرضية، مجتمع التجربة والمقارنة، فترة/حجم مقترح وأساسه، تعريف النجاح ومقاييس الحماية وعتباتها وصفتها، قرار المتابعة أو التعديل أو الإيقاف، المسؤول والتفويض المطلوب، التدريب والإجراء والدعم والانتقال والتراجع:

| القياس بعد التجربة | النتيجة الفعلية ودليلها | الفرق بعد ضبط مزيج الحالات | حدود الاستنتاج | القرار ومالكه |
|---|---|---|---|---|
| | | | | |

إذا لم تبدأ التجربة، أبقِ النتائج «لم تُقَس بعد»؛ لا تعرض التوقع كنتيجة.
