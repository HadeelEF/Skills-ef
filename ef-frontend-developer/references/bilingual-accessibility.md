# العربية والإنجليزية وإمكانية الوصول

## Locale is application state

نفذ اللغتين ضمن النطاق المتفق عليه، بما فيه العناوين والأفعال والتحقق
والانشغال والفراغ والخطأ والنصوص الميسرة. استخدم مفاتيح محتوى مستقرة ونظام
الترجمة القائم؛ تجنب نشر شروط اللغة داخل كل جزء من JSX أو تركيب الجمل
من مقاطع قد يختلف ترتيبها بين اللغتين.

اختر **ترتيب أولوية واحدًا** لمصدر اللغة ووثقه حسب المنتج: مثل مسار URL،
ثم تفضيل محفوظ، ثم افتراضي المشروع. إن استُخدمت لغة المتصفح فحدد موضعها
في الترتيب؛ لا تدعها تتنافس مع اختيار المستخدم الصريح. تحقق من القيم
المدعومة واجعل أول عرض من الخادم والعميل متوافقًا.

اضبط `lang` و`dir` على جذر المستند أو النطاق الصحيح. تغيير ترجمة الكلمات
وحدها لا يغير اتجاه التخطيط أو نطق قارئ الشاشة. في التطبيقات ذات المسارات
المترجمة، احفظ الرابط العميق وما يلزم من search params عند التبديل.

حافظ على سياق المستخدم: الصفحة والبحث والمرشحات والمدخلات غير المرسلة
بقدر ما يقتضيه المنتج. لا تجعل تغيير اللغة يمحو النموذج أو يعيد الصفحة
الأولى بلا قرار تصميم مبرر. في next-intl اتبع تكامل النسخة الموجودة:
[Routing](https://next-intl.dev/docs/routing).

## Bidirectional layout and text

- استخدم `margin-inline` و`padding-inline` و`inset-inline` و`text-align:start`
  ونظائرها، أو utilities المناظرة التي تدعمها نسخة Tailwind. راجع الاستثناء
  المقصود بدل استبدال كل left/right آليًا.
- اجعل ترتيب DOM يعكس القراءة والتنقل المنطقي؛ تجنب عكس ترتيب بصري يجعل
  تسلسل Tab مخالفًا له. احذر عكس الحاوية ثم عكس الأيقونة مرة ثانية.
- اعكس الدلالات الاتجاهية مثل السابق/التالي وفق اللغة، ولا تعكس الشعار
  والصور والأيقونات غير الاتجاهية تلقائيًا.
- اعزل المعرفات والبريد والروابط والأجزاء المختلطة بـ`bdi` أو اتجاه محلي
  مناسب. لا تحول كامل الواجهة إلى LTR لإصلاح حقل بريد واحد.
- افحص محاذاة القوائم المنبثقة والـportals والحوارات والتلميحات والمكوّن
  المركب؛ وراثة CSS لا تضمن أن مكتبة خارج شجرة المحتوى تلتقط الاتجاه.
- إذا استُخدمت shadcn/ui، افحص طريقة RTL الخاصة بإصدار المشروع وتكوينه؛
  لا تعتمد على وصفة قديمة أو تفترض أن component جاهز يدعم الاتجاه تلقائيًا.

مراجع: [W3C: HTML direction](https://www.w3.org/International/questions/qa-html-dir)،
[Tailwind positioning](https://tailwindcss.com/docs/top-right-bottom-left)،
[shadcn/ui RTL](https://ui.shadcn.com/docs/rtl).

## Locale-aware content

استخدم Intl للأعداد والعملات والتواريخ وصيغ الجمع بما يتفق مع متطلبات
المحتوى. حدد نظام الأرقام والتقويم والمنطقة الزمنية عندما يؤثر في المعنى؛
لا تساوِ بين «لغة عربية» وقرار استخدام تقويم أو أرقام معينين.

التاريخ المدني مثل يوم استحقاق بلا وقت ليس بالضرورة timestamp UTC؛ تجنب
تحويلًا يغير اليوم بسبب المنطقة الزمنية. احتفظ بالمعرفات كنصوص للحفاظ على
الأصفار والرموز. تنسيق المبلغ لا يحدد عملته، ولا يجوز اختراع وحدة ناقصة.

افحص أطوال النص الفعلي باللغتين والتفافه. وفّر صياغة ذات معنى عند تعذر
معلومة بدل عرض `undefined` أو مفتاح ترجمة. لا تدع اللغة البديلة تخفي نقصًا
في نص وظيفي مطلوب ضمن النطاق.

## Accessible interaction

اتبع متطلبات المشروع، واستهدف WCAG 2.2 AA للأجزاء المنفذة حيث ينطبق، دون
إعلان امتثال شامل نتيجة فحص آلي محدود.

| الجزء | ما يجب أن يحدث فعليًا |
| --- | --- |
| الصفحة | عناوين ومناطق دلالية، عنوان صفحة مناسب، ووسيلة تجاوز التنقل عند الحاجة |
| التحكم | اسم واضح، عنصر أصلي متى أمكن، focus مرئي، وتشغيل بلوحة المفاتيح |
| النموذج | label مرتبط، تعليمات مفهومة، ربط رسالة الخطأ بالحقل، وعدم الاعتماد على placeholder وحده |
| الحوار والقائمة | إدارة focus والسلوك الملائم لنمط المكوّن؛ منع تسربه من modal وإعادته عند الإغلاق |
| النتائج الديناميكية | إعلان موجز مفيد عند الحاجة دون إعادة نطق كل الشاشة أو تحريك التركيز بلا سبب |
| الحالات | معنى نصي أو رمزي بجانب اللون، مع إمكانية معرفة الانشغال والنتيجة |
| الصور والأيقونات | بديل يصف الوظيفة، وإخفاء الزخرفي عن شجرة الإتاحة دون إخفاء المعلومة |

تحقق من تباين النص والأجزاء التفاعلية في حالاتها الفعلية. المرجع المعتاد
AA: 4.5:1 للنص العادي و3:1 للنص الكبير بحسب تعريف المعيار، و3:1 للعناصر
غير النصية ذات الصلة مع مراعاة الاستثناءات. لا تعامل الأزرار المعطلة
أو الشعارات مثل النص الوظيفي العادي في القياس.

افحص إعادة تدفق المحتوى والتكبير وعدم حجب التركيز. معيار حجم الهدف الأدنى
في WCAG 2.2 AA يحدد 24×24 CSS px أو شروط استثناء منها التباعد؛ يمكن اختيار
أهداف لمس أكبر للراحة. هذه مساحة تفاعل ولا تستبدل مقاس الشعار من دليل الهوية.

الاختبار الآلي يكشف جزءًا من المشكلات. راجع لوحة المفاتيح والتركيز والنصوص
والسلوك يدويًا بأدوات المتصفح المتاحة. اذكر إن اختُبر قارئ شاشة فعلًا؛ لا
تسمِّ فحص الشجرة الميسرة اختبارًا بقارئ شاشة.
مراجع: [WCAG 2.2](https://www.w3.org/TR/WCAG22/)،
[Focus not obscured](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html)،
[Target size](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html).
